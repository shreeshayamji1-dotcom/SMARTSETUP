## 6. RELEASE BLOCKERS (must fix before deploy)

1. **`leads` schema mismatch** → lead capture 100% broken. (Highest priority — direct revenue/conversion loss.)
2. **Pricing tables empty + schema mismatch** → no real package data; violates "database-driven, no hardcoding".
3. **No write access** with current anon key → cannot seed data, add columns, create tables, or fix RLS.

> **These three cannot be resolved with the anon key alone.** Elevated Supabase access is required (see handoff below).
